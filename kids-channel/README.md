# قناة أطفال — تجربة أولى: حرف الباء

فيديو ٣٠ ثانية مرسوم ومتحرك بالكامل بالكود (`make_video.py`)، ويا موسيقى ومؤثرات صوتية مولّدة.

- الفيديو: `out/letter_baa.mp4`
- صورة مصغّرة: `out/thumbnail.png`
- إعادة التوليد: `python3 make_video.py` (يحتاج Python + Pillow + numpy + ffmpeg)

## نص التعليق الصوتي (تسجّله انت بصوتك)

| الوقت | المشهد | الكلام |
|---|---|---|
| 0:00 | دودو يمشي | هلا حبايبي! أني دودو البطة! |
| 0:02 | العنوان | اليوم راح نتعلم حرف… الباء! |
| 0:05 | يطلع حرف ب بلا نقطة | شوفوا هذا الحرف… شي ناقصه؟ |
| 0:06 | النقطة توگع | إيييه! نقطة وحدة جوّه! هذا حرف **ب** |
| 0:08 | أشكال الحرف | ب بأول الكلمة، وبالنص، وبالآخر |
| 0:10 | بطة | **ب**… **بطة**! مثلي أني! كواك كواك |
| 0:15 | باب | **ب**… **باب**! طق طق، منو بالباب؟ |
| 0:20 | بيت | **ب**… **بيت**! بيتنا الحلو |
| 0:25 | الختام | ب بطة، ب باب، ب بيت! نشوفكم بالحرف الجاي، اشتركوا حبايبي! |

## الخطة

1. **فيديو واحد بالأسبوع**: كل حرف بفيديو، يعني ٢٨ فيديو للحروف كلها. وبعدها الأرقام والألوان والحيوانات.
2. انت تسجّل الصوت، وأني أدمجه ويا الفيديو وأضبط التوقيت.
3. الشخصية الثابتة (دودو البطة) تعطي القناة هوية، وتبعدها عن تصنيف "محتوى مكرر".
4. على يوتيوب: اختار **"Made for Kids"** (إجباري لمحتوى الأطفال).
